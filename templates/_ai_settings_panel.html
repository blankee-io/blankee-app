1

Get a Claude API key

Blankee can ask Claude to suggest a category and tidy the merchant name for each imported transaction. It runs on your key, so you control it and pay Anthropic directly, from usage credits you buy in advance.

What it costs: at today's prices, roughly 25¢ per 1,000 transactions on Claude Haiku 4.5 - for most users a few cents a month. Anthropic bills by usage and changes its prices, so treat this as an estimate, not a quote; your usage shows on platform.claude.com.

Sign in at platform.claude.com, add a payment method under Billing, then create a key under API keys. A Claude Pro or Max subscription does not include API access; the key is separate.

Nothing else is sent, and Anthropic's API terms do not use it for training. Your key stays stored, encrypted, even if you turn this off or disconnect your bank.
