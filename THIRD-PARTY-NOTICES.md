**Licences:** icons **CC BY 4.0**, fonts **SIL OFL 1.1**, code **MIT**
**Copyright:** Fonticons, Inc. — <https://fontawesome.com>

Font Awesome describes Free as *"free, open source, and GPL friendly"*, which is
what makes it safe to ship inside an AGPL-3.0 project. The full text is at
`static/fontawesome-free/LICENSE.txt`, which travels with the fonts because CC BY
and the OFL both require it. The OFL reserves the font name "Font Awesome" — a
modified version of the font files would need renaming.

Only what the application needs is bundled, 216KB in total:

| file | bytes |
|---|---|
| `css/all.min.css` | 75,736 |
| `webfonts/fa-solid-900.woff2` | 114,740 |
| `webfonts/fa-regular-400.woff2` | 18,924 |
| `LICENSE.txt` | 7,427 |

There is no brands webfont: the application uses no `fa-brands` icons.
`all.min.css` still declares an `@font-face` for it, which costs nothing, since a
browser only fetches a font when a glyph needs it. The same applies to
`fa-v4compatibility`.

`fa-regular-400.woff2` is present solely for the three Kit fallbacks that keep a
lighter weight — see below.

## Font Awesome Pro — optional, NOT bundled

**Path when installed:** `static/fontawesome/` (gitignored)
**Licence:** commercial, per-seat — <https://fontawesome.com/license>

Pro is commercial software and is deliberately absent from this repository.
Redistributing it would hand a paid seat to anyone who cloned the project, which
is not ours to grant — and no licence on Blankee could change that.

If you hold a Pro licence, drop your build into `static/fontawesome/` and the
application uses it automatically. See the **Icons** section of the
[README](README.md) for the expected layout. Without it, the bundled Free build
plus `static/css/fa-pro-fallback.css` renders every icon.

### What depends on Pro

`static/css/fa-pro-fallback.css` is generated by
`install/build_fa_fallback.py` from `install/fa_fallback_map.json`, which maps
**35** Pro and Kit icons onto Free glyphs. Run the generator with `--check` to
fail on any Pro icon used without a fallback.

Weight is preserved where Free allows it. Free's regular family is only ~163
icons, so a light Pro icon can stay light only when its replacement is one of
them. Three are; the rest render solid.

## A note on AGPL section 13

Blankee is served over a network, which engages AGPL-3.0 section 13: users
interacting with it remotely must be offered the corresponding source. In
practice that means a visible link to the source repository in the running
application. That obligation falls on whoever operates an instance.
