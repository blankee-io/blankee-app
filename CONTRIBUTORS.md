# Contributors

Everyone whose work is in Blankee, with the release their first change shipped in.

| Who | What | Since |
|---|---|---|
| **Adrián Bosada** ([@drawnkard](https://github.com/drawnkard)) | author and maintainer | 1.0.0 |
| **Camden Zupon** ([@camden-blankee](https://github.com/camden-blankee)) | early application work, and the first version of the iOS app | 1.0.0 |

Development happened in a private repository until 1.45.0; its history is part of
this one now, so `git log` and GitHub's contributor graph show that work where it
belongs.

If you send a pull request, your name goes here when it ships. Say how you would
like to be named if it is not the name on your commits; whoever merges fills in
the release.
